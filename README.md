# Coffee House Café

Создай современный профессиональный сайт для кофейни под названием Coffee House. Стильный минималистичный дизайн. Первый экран с фотографией кофе, меню с 8 напитками и ценами, раздел О нас, галерея, контакты, кнопка связи, адаптация под мобильные телефоны, плавные анимации. Все кнопки должны работать. Используй бежевые, коричневые и белые оттенки.
